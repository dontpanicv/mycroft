What this establishes—and what still needs a phone

The local source mutation, runtime replacement, checkpoint restoration, system intent invocation, progress timeout, and cancellation handling were exercised. The ten-minute run had a maximum observed tick gap of 1.072 seconds.

A physical iPhone is still required to measure admitted background-task lifetime, secure lock, battery/thermal/memory pressure, Live Activity cancellation, and real network/model delays. The simulator results do not demonstrate unattended 24/7 execution.

Source and checkpoint writes are separate in this spike. Recovery was tested after a complete checkpoint; a production host needs atomic version activation and recovery for crashes during the handover. Only explicit JSON state is restored, not arbitrary JavaScript stacks or closures.

After the display experiment, the simulator reported power on but showed a black screen. Later UI testing required a simulator restart and Home press. A separate URL-based recovery harness encountered an Open-in-app confirmation; the final recovery test used native UI buttons.
