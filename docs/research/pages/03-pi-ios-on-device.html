A user action requests continued background execution. When iOS grants it, the native host runs the agent. Leaving the app does not itself tear down this runtime.

The UI can use editable HTML/CSS/JS in a WKWebView; background agent execution belongs to the native-owned JavaScriptCore runtime. In this design, model inference may use an API, while code edits, reloads and state restoration happen locally.

Existing building blocks: PiDurableKit supports agent-written JS extensions. Full self-replacement requires adapting its currently bundled-source loader and adding safe lifecycle management.
