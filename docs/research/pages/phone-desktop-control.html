Boundaries that matter for this design

GUI authority lives on the Mac. The native helper needs Accessibility permission. Images need the separate screen-capture permission. An SSH login does not itself grant either. Keep the helper in the intended logged-in desktop session; an unlocked interactive desktop is the baseline for full input control.


Element refs belong to an observation. Bind actions to environment, desktop/window identity, state ID, and target ref. Re-observe changed state and serialize shared keyboard/mouse use. A successfully delivered event is not proof that the application did the intended thing.


Phone suspension pauses the brain. Remote hands cannot keep the iPhone's JS loop alive. After reconnecting, inspect pending action receipts and fresh UI state before choosing another action. A durable log is not an exactly-once guarantee for desktop side effects.


Stock pi-env has connection-bound command lifetime. In the reviewed protocol revision, loss of stdin or 30 seconds without incoming data kills daemon-owned command groups. Persistent desktop execution/receipts require an independently hosted helper; a background shell command is not sufficient.


Accessibility is incomplete in some apps. Prefer APIs/CLI for structured work, then AX controls, then browser DOM or screenshots/input for surfaces with missing semantics. Jev selects from candidates; it does not generate an email or implement an unknown tool. Ask the planner for that content or behavior.
